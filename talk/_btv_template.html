framing  //  20 seconds Say it once and move. Do not answer it here. The room should get to the answer about one slide before you do.

What is an AI agent?

A model with tools and a loop around it: plan, call a tool, read the result, decide again.

Uses tools

The agent acts on other systems. It can look up an order, query a database, or issue a refund.

Decides what to do next

It picks the next action from the task and from what the last step returned. The path is not fixed in advance.

We need to evaluate the whole process

Checking the final response tells us the answer is correct. It does not tell us how the agent got there.

Things can go wrong along the way

It might pick the wrong tool, pass a wrong argument, or repeat a call, and still land on the right answer.

terminology  //  1 minute Half the room builds these for a living and half have never written a prompt. Read the lead, then take the four boxes in order without reading them word for word. The bottom left box is the one that matters for this talk, so slow down there.

What is LLM as a judge?

A second model reads the first model's output and scores it, so nobody reads every case by hand.

Reads another model's work

It gets the request, the response, and sometimes the whole trace, and returns a number.

Handles volumes people cannot

A person needs minutes per case. The judge costs a fraction of a cent and runs overnight. That is why we started using one.

It explains itself convincingly

It also writes a paragraph explaining the score. That paragraph is written to read well, and nothing checks it.

It is also a model

Give it the same input twice and you can get two answers. Sometimes you get nothing back. We test the agent for this. We rarely test the judge.

What the judge actually receives

Then we noticed some rows had no score

What came back

Not a zero, not an error message, not a refusal. Just an empty string where a number should be.

What we did first

We dropped those rows and carried on. That is one call to dropna, and it is in almost every eval script I have written.

the turn  //  1 minute Slow down. This is the hinge of the talk. Admit the dropna without embarrassment, because everybody in the room has written it, and that honesty buys you the next ten minutes.

What could cause an empty score?

a missing policy reference a photo that failed to upload a trace too long for the context our own parser the provider safety filter something in the API itself

Six things it could be. Five of them are our own code, which is where I expected to find it.

So we sent the same ten inputs again

0 blank rows picked at random
0 returned a valid score on the retry
0 changes to the input

Ten is a small sample, so this tells us blanks can be recovered, not how often they happen. One possibility is that the call is nondeterministic and sometimes returns nothing. We could not see inside the API, so we do not know for certain.

the case  //  1.5 minutes Slow, no hedging. This is where the talk stops being about a metric. Land the middle block and stop talking for two seconds.

I had seen the same thing in my own work

I work on multimodal safety, so my models look at a picture and decide whether to help.

One of them refused a request and was very specific about why. It named the dangerous object, said where it was in the frame, and declined on those grounds.

The object was not in the image. I had removed it in the previous step.

My evaluation scored that refusal as correct, because by the criteria I had written, it was.

personal  //  1 minute First person, quiet. Then draw the line explicitly: it is the same failure as the refund letter, in a different domain. That is why you started auditing judges at all.

What the judge was actually rewarding

What it scored highly

Clear structure, specific detail, a named piece of evidence, and a justification that sounds like policy.

By those criteria both examples are good writing.

What we meant to measure

Whether the decision was actually based on what was in front of it.

We never put that question in the judge prompt.

A graded judge tells us whether something was handled well. We never asked it whether it was right.

interpretation  //  1 minute The transfer to the room: an agent that pays out confidently on the wrong evidence scores high for exactly the same reason. Say it explicitly.

Adding the reference changed the judge's behavior

These are directions we saw, not effect sizes we would publish. The practical version: the judge can only check what it can see. If the thing you care about is not in its input, no prompt wording gets it back.

What we check before trusting a judge number

CheckWhat to publish beside the number
Repeatscore the same inputs three times, report the spread as well as the mean
Countthe blank rate, broken down by how hard the case was, never a silent dropna
Compareagreement with humans on a sample, with the trivial baseline printed beside it
Separatequality and correctness as two questions, not one score

None of this is clever, and that is the point. The checks are cheap. The repo runs all four on your CSV.
